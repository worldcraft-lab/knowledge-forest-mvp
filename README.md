# knowledge-forest-mvp

Knowledge Forest MVP v0.2.

Seed・Branch・Trial・Sigma・Systemの流れで、気づきや実践知をツリー化し、組織の経験を知識・仕組み・制度へ育てるためのローカルMVPです。

## v0.2の目的

v0.1の「投稿ビューア」から、v0.2では「知識成長ビューア」へ移行します。

中心は投稿一覧ではなく、以下です。

- Forest単位で知識空間を分ける
- SeedからSystemまでの成長を可視化する
- Sigmaを統合フェーズとして中心に置く
- ツリーごとの成長率・統合率・制度化候補を見える化する
- 検索結果を単発投稿ではなく、関連ツリーとして表示する

## 技術方針

- Next.js
- TypeScript
- Tailwind CSS
- React Flow
- LocalStorage only
