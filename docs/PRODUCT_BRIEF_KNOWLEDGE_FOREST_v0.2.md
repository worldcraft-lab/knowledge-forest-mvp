# Product Brief - Knowledge Forest v0.2

## 一言定義

Knowledge Forestは、組織の経験をSeedからSystemへ育てるための知識成長ビューアである。

## v0.2の立ち位置

v0.1:
- 投稿を作る
- 投稿を見る
- 投稿をツリー表示する

v0.2:
- Forestを作る
- 知識の成長状態を見る
- Sigmaによる統合を中心に置く
- System化候補を発見する

## 中核思想

投稿は目的ではない。
投稿は、経験が知識へ成長する途中の状態である。

Knowledge Forestは、以下の変換を見るための道具である。

```text
Low: 現場の気づき・実践
↓
Mid: 改善案・統合・再現性
↓
High: 制度化・共有・社会接続
```

## 投稿Phase

| Phase | 日本語 | 意味 |
|---|---|---|
| Seed | 気づき | 現場で得た小さな発見 |
| Branch | 改善案 | 気づきから生まれた仮説・提案 |
| Trial | 実践報告 | 実際に試した結果 |
| Sigma | 統合・まとめ | 複数の知見をまとめ、意味づける |
| System | 制度化・マニュアル | 誰でも使える形にしたもの |

## v0.2で追加する概念

### Forest

Forestは、知識ツリーの集合体である。

例:
- StoS Internal
- 学生OEM
- Craft Operations
- 奉還町プロジェクト
- 店舗改善

### Knowledge Tree

Treeは、1つのテーマに対する知識の成長経路である。

例:
```text
接客時の報連相が曖昧
├ 報告テンプレート案
│ ├ 週次で試した結果
│ └ Sigma: 報連相ルールの整理
└ System: 新人向け報連相マニュアル
```

### Sigma Center

Sigmaは単なる投稿種別ではなく、知識を統合する中心点である。

v0.2では、Sigmaが存在するツリーを「統合済み」と扱う。

### Growth Indicators

Forestごとに以下を表示する。

- Node数
- Seed数
- Trial数
- Sigma数
- System数
- Sigma到達率
- System化率
- 止まっているTree数
- System化候補数
