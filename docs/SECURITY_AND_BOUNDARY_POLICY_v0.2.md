# Security and Boundary Policy v0.2

## Local-first

v0.2はLocalStorageのみ。
外部送信しない。

## Private by default

サンプル以外の実データを公開しない。
GitHub repositoryはPrivate推奨。

## Not HR evaluation

人の能力を順位付けしない。
貢献傾向は表示してよいが、評価・査定・ランク付けUIにはしない。

## Not public proof

以下の表現は禁止。

- 実証済み
- 社会実装済み
- 検証完了
- 導入企業多数
- AIが自動で制度化する

## AI scope

v0.2ではAI APIを使わない。
将来的なAI補助はdocsに書いてよいが、実装しない。

- Phase分類補助
- Sigma候補生成
- System草案生成
- 重複統合
- 停滞Tree発見
